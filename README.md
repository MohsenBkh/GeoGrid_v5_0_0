# GeoGrid و SwitchLoc

این مخزن شامل دو برنامهٔ مستقل است:

- **GeoGrid** (`shp2dgs`): تبدیل لایه‌های Shapefile شبکهٔ توزیع به فایل Excel با ساختار DGS برای ورود به DIgSILENT PowerFactory، با امکانات تنظیم لایه‌ها، کتابخانهٔ تجهیزات و پیش‌نمایش دیاگرام.
- **SwitchLoc** (`switchloc`): ابزار اولیهٔ مطالعهٔ جایابی کلید، رتبه‌بندی فیدر، بررسی خاموشی و تحلیل اکتشافی شبکه‌های شعاعی تک‌فیدری و چندفیدری.

> **وضعیت مهندسی SwitchLoc:** این بخش هنوز کامل یا معتبر برای تصمیم اجرایی نیست. نتایج، به‌خصوص جایابی چندفیدری و بازیابی بار، غربالگری اکتشافی‌اند و باید با داده‌های تأییدشده و کنترل‌های مستقل مهندسی بررسی شوند. انطباق کامل با TAV122-02/00 ادعا نمی‌شود.

نام مخزن نشان‌دهندهٔ مسیر توسعهٔ GeoGrid 5.0.0 است؛ نسخهٔ فعلی برنامهٔ GeoGrid در کد، `4.2.0` است. راهنمای پیشین GeoGrid برای حفظ جزئیات در [سند تاریخی نسخهٔ 3.5](docs/geogrid_legacy_reference.md) نگهداری شده و مرجع وضعیت فعلی نیست.

## پیش‌نیاز و نصب

- Python 3.9 یا جدیدتر. برای ساخت نسخهٔ انتشار GeoGrid با `BUILD.bat`، نیازمندی‌های همان اسکریپت، از جمله Python و کامپایلر C مناسب، را بررسی کنید.
- **GeoGrid:** وابستگی‌های `requirements.txt` شامل PySide6، `cryptography`، `pyshp` و `openpyxl` است. برای قابلیت اختیاری GPS و تبدیل مختصات GeoGrid، `pyproj` نیز لازم است.
- **SwitchLoc:** علاوه بر `pyshp` و `openpyxl`، از `networkx`، `python-docx` و رابط **Tkinter** استفاده می‌کند. Tkinter باید همراه نصب Python سیستم موجود باشد؛ رابط GeoGrid و SwitchLoc مجزا هستند و به‌ترتیب از Qt و Tkinter استفاده می‌کنند.

در پوشهٔ اصلی مخزن:

```bash
python -m pip install -r requirements.txt
python -m pip install -e .
# اختیاری، برای GPS در GeoGrid:
python -m pip install pyproj
```

نصب `-e .` فرمان‌های `geogrid`، `shp2dgs` و `switchloc` را ثبت می‌کند. اجرای رابط گرافیکی به محیط دارای نمایشگر نیاز دارد.

## اجرای GeoGrid

```bash
python -m shp2dgs
# یا:
python shp_to_dgs.py
```

برای تبدیل از خط فرمان، پس از فعال‌سازی مجوز و داشتن دسترسی موردنیاز:

```bash
python -m shp2dgs --shp /path/to/shapefiles --out output.xlsx --no-gui
```

با `python -m shp2dgs --help` گزینه‌های موجود، از جمله نگاشت لایه با `--layer`، محدودهٔ MV/LV و تنظیمات GPS را ببینید. فایل خروجی را از بخش DGS Import در PowerFactory وارد و نتیجه را بررسی کنید.

### فعال‌سازی و امنیت

GeoGrid برای تبدیل به مجوز فعال نیاز دارد. برای ساخت درخواست فعال‌سازی و سپس وارد کردن فایل مجوز دریافتی می‌توان از پنجرهٔ فعال‌سازی برنامه یا دستور زیر استفاده کرد:

```bash
python geogrid_activate.py
```

**هشدار امنیتی:** در مسیر `GeoGridLicenseManager/keys/` فایل کلید خصوصی در مخزن وجود دارد. پیش از انتشار عمومی یا توزیع پروژه، دسترسی و اعتبار آن را بررسی کنید؛ خصوصی‌کردن مخزن پس از انتشار لزوماً اثر افشای قبلی را برطرف نمی‌کند. در صورت افشا، کلید باید طبق سیاست امنیتی پروژه جایگزین شود.

## اجرای SwitchLoc

```bash
python -m switchloc
# یا پس از نصب بسته:
switchloc
```

### گردش کارهای موجود

| کار | روش استفاده و خروجی |
|---|---|
| رتبه‌بندی فیدر | «ساخت قالب Excel»، جایگزینی داده‌های نمونه و سپس «ورود و رتبه‌بندی»؛ خروجی Excel یا CSV شامل اجزای امتیاز. |
| EP و TL | «قالب EP/TL» شامل مثال جدول ۱۵ است؛ پس از ورود نتایج **تأییدشدهٔ مستقل** سناریوها، شاخص‌ها محاسبه و صادر می‌شوند. |
| تک‌فیدری | «قالب شبکه» برای واردکردن گره، شاخه، بار و دادهٔ خرابی؛ سپس «جایابی اکتشافی» یا «مقایسه طرح‌ها». شبکه باید شعاعی و متصل باشد. |
| چندفیدری | «قالب چندفیدری» را تکمیل و با «ورود شبکه و نقشه» باز کنید. رابط‌های بین فیدرها، ظرفیت و رزرو باید صریح وارد شوند. با «بهینه‌سازی» نقاط و با کلیک روی شاخه‌های مجاز انتخاب دستی را بررسی کنید. |
| خاموشی | «بررسی خاموشی» فایل نمونهٔ ۱۴۰۵ را می‌خواند. با «خروجی بازبینی خاموشی» فایل جداگانه بسازید، طبقه‌بندی و علت حذف را دستی تکمیل کنید و با «خلاصه بازبینی» بررسی کنید. |
| N-1 اکتشافی | «قالب N-1» و داده‌های زون، اتصال و رزرو را تکمیل کنید؛ خروجی شامل سناریوها و هشدارهاست. |
| پروژه و گزارش | ذخیره/بازکردن پروژهٔ SQLite، خروجی Word اولیه و قابل ویرایش، و خروجی‌های Excel و CSV. خروجی Shapefile نقاط تک‌فیدری به مختصات و فایل PRJ منطبق نیاز دارد. |

قالب‌ها دادهٔ فرضی دارند؛ قبل از هر مطالعه آن‌ها را با اطلاعات واقعی و تأییدشده جایگزین کنید. ورودی‌های اصلی را دست‌نخورده نگه دارید و خروجی‌ها را در مسیرهای جدا ذخیره کنید.

### نقشه و محدودیت‌های مهم

- نقشهٔ چندفیدری یک **نمای برداری آفلاین شبکه** در مختصات واردشده است، نه نقشهٔ پایهٔ جغرافیایی. چرخ ماوس بزرگ‌نمایی، کشیدن با دکمهٔ راست جابه‌جایی نما و کلیک روی شاخهٔ مجاز تغییر انتخاب است. پس از تغییر، نتیجه دوباره محاسبه می‌شود.
- جستجوی چندفیدری از سناریوهای خطای زون و جریان بیشینه با ظرفیت رابط و رزرو پشتیبان استفاده می‌کند. این مدل امکان تقسیم بار و تغذیهٔ حلقوی را می‌دهد و **پخش بار، ولتاژ، حفاظت، شعاعی‌سازی، توالی مانور و ظرفیت مسیر اصلی را تأیید نمی‌کند**. نتیجه خوش‌بینانه است و برنامهٔ مانور نیست.
- مختصات پیشنهادی مختصات گره پایین‌دست است، نه لزوماً محل نهایی نصب؛ پوشش مخابرات باید جداگانه بررسی شود. استخراج خودکار مدل توپولوژی از GIS/DGS و تبدیل CRS در SwitchLoc پیاده‌سازی نشده است.
- در مدل تک‌فیدری، ENS و مقایسهٔ E1/E2 تحت فرضیات ساده‌شدهٔ شبکهٔ شعاعی بدون پشتیبان محاسبه می‌شوند؛ بخش اقتصادی کامل و شاخص CE/CN پیاده‌سازی نشده‌اند.
- فایل خاموشی ۱۴۰۵ به‌تنهایی پوشش شش‌ساله ندارد. طبقه‌بندی خودکار رخداد، نتیجه‌گیری قابلیت اطمینان کامل، گزارش PDF و نسخهٔ اجرایی اعتبارسنجی‌شده هنوز فراهم نیستند.

جزئیات ورودی، فرضیات، محدودیت‌ها و آزمون‌ها: [راهنمای فارسی SwitchLoc](docs/switchloc_fa.md).

## فایل‌های نمونه و مرجع

- `Sample shape file.rar`: دادهٔ نمونهٔ GIS. برای فهرست‌برداری لایه‌ها در SwitchLoc ابتدا آرشیو را جداگانه استخراج کنید؛ این کار به معنی ساخت خودکار توپولوژی نیست.
- `لیست خاموشی های 1405.xlsx`: دادهٔ خام نمونهٔ خاموشی برای ورود و بازبینی دستی.
- `راهنمای اجرایی گام به گام مطالعات جایابی کلید TAV122-02.html`: راهنمای مرجع مطالعات؛ محاسبات پیاده‌شده باید در چارچوب فرضیات و محدودیت‌های ثبت‌شده بررسی شوند.
- `config.json`، `dgs_template.json` و `types_override.xlsx`: تنظیمات و کتابخانه‌های مورد استفادهٔ GeoGrid.

## ساخت ویندوز

- **GeoGrid:** اسکریپت `BUILD.bat` مسیر ساخت انتشار با Nuitka و مراحل مربوط به هسته و فعال‌سازی را اجرا می‌کند. پیش‌نیازها و مسیر خروجی در خود اسکریپت توضیح داده شده‌اند.
- **SwitchLoc:** اسکریپت `BUILD_SWITCHLOC.bat` وابستگی‌ها و PyInstaller را نصب و فایل‌های ساخت را تولید می‌کند؛ خروجی پیش‌فرض در `dist/SwitchLoc/` است. ساخت و اجرای آن روی ویندوز تمیز باید پیش از توزیع مستقل آزمایش شود.

هیچ‌یک از این اسکریپت‌ها به‌تنهایی به معنای اعتبارسنجی مهندسی یا آماده‌بودن نصب‌کنندهٔ نهایی نیست.

## آزمون

```bash
python -m pip install pytest
python -m pytest -q
# فقط آزمون‌های SwitchLoc:
python -m pytest -q tests/test_switchloc.py
```

آزمون‌ها شامل نمونه‌های روابط و رتبه‌بندی، کنترل داده‌ها، خواندن فایل خاموشی نمونه، خروجی‌ها و مدل‌های اکتشافی هستند. برای اجرای آزمون فایل واقعی، فایل `لیست خاموشی های 1405.xlsx` باید در ریشهٔ مخزن موجود باشد. آزمون خودکار جایگزین آزمون رابط گرافیکی ویندوز و تأیید نتایج توسط کارشناس نیست.

## ساختار اصلی

```text
shp2dgs/                 موتور، رابط، تبدیل DGS و مجوز GeoGrid
switchloc/               موتورهای مطالعاتی و رابط اولیه SwitchLoc
GeoGridLicenseManager/   ابزار مدیریت مجوز؛ شامل اطلاعات حساس
build_tools/             ابزار ساخت GeoGrid
docs/                    مستندات و راهنمای فارسی
tests/                   آزمون‌ها
BUILD.bat                ساخت انتشار GeoGrid در ویندوز
BUILD_SWITCHLOC.bat      ساخت اولیه SwitchLoc در ویندوز
```
